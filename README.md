# 📏 Anti-AI Distance

Приложение для измерения расстояния от экрана до лица с использованием компьютерного зрения (MediaPipe Face Mesh).

## Возможности

- 🎥 Детекция лица и глаз в реальном времени
- 📏 Расчёт расстояния в сантиметрах
- 🚦 Светофорная индикация: зелёный (30-40 см), жёлтый, красный
- ⚙️ Калибровка по расстоянию между глазами (по умолчанию 6.5 см)
- 💾 Сохранение и экспорт замеров (.txt)
- 🛡️ Полностью офлайн, данные только на устройстве
